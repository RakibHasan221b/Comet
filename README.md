NVIDIA Stock Prediction with LSTM
This project uses an LSTM (Long Short-Term Memory) neural network to predict NVIDIA's stock price based on historical data from Yahoo Finance.

Files
Nvidia.ipynb: The Colab notebook with the code to download NVIDIA stock data, preprocess it, train the LSTM model, and evaluate its performance.
nvda_lstm_model.pth: The trained model file.


Setup & Running the Code
1. Clone this repository to your local machine.
2. Open Nvidia.ipynb in Google Colab.
3. Run the notebook step by step. Make sure you have an internet connection since it downloads stock data from Yahoo Finance.
4. After running the cells, the model will be trained, evaluated, and visualized.
